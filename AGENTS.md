Whenever designing, building, modifying, or reviewing any user interface or frontend code in this workspace, ALWAYS actively consult and apply the installed Top 10 UI/UX, Frontend, and Apple Design skills:

1. **ui-ux-pro-max**: Searchable palettes, typography scale, responsive layouts, and stack-specific best practices.

7. **shadcn**: Reusable component architecture, accessible primitives, and consistent theming.

9. **baseline-ui**, **fixing-motion-performance**, & **fixing-accessibility**: Spacing hierarchy, compositor-only motion without jank, WCAG compliance.

## Mandatory Directives for Every Prompt & Turn
- **Design Bar**: Strive for award-winning, stunning visual quality with modern typography, tasteful color harmonies, and responsive depth. Never output generic or unfinished UI.
- **Micro-interactions**: Incorporate fluid hover states, smooth transitions, and spring feedback using compositor properties (`transform`, `opacity`).
- **Accessibility & Craft**: Ensure keyboard focus, ARIA attributes, semantic HTML, and correct viewport units (`h-dvh`).
- **Consistency**: Reference and respect `PRODUCT.md` and `DESIGN.md` in the project root.
